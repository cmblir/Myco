# 미코 영상 모션 사용법

제공한 `myco_mov.mp4`와 `myco_base.png`를 바탕으로 만든 영상 모션 15종입니다.
투명 영상, 정지 이미지, 미리보기 화면, 추가 동작 제작 지시문이 들어 있습니다.

## 바로 사용하기

1. 압축 파일을 풀고 폴더 안의 `index.html`을 브라우저로 여세요.
2. 원하는 카드에서 **재생**을 누르세요. 한 번에 하나씩 재생됩니다.
3. 사용할 곳에 맞는 파일을 받거나 `clips` 폴더에서 가져오세요.

새로운 ‘돋보기로 살펴보기’, ‘아이디어’, ‘고개 인사’, ‘메모 정리’를 먼저 보여줍니다. 이전 모션 11종은
접힌 목록을 열어 볼 수 있고, 목록을 닫으면 안에서 재생하던 영상도 멈춥니다.

| 압축 파일             | 들어 있는 파일                                                   |
| --------------------- | ---------------------------------------------------------------- |
| `myco-video-web.zip`  | 투명 WebM·HEVC, 밝은 배경 MP4, PNG 정지 이미지, 미리보기, 사용법 |
| `myco-video-pack.zip` | 웹용 파일 전체 + 영상 편집용 ProRes 4444 MOV                     |

웹용 압축 파일에는 편집용 MOV가 없습니다. 편집 프로그램에서 사용할 때는
**모든 형식 받기**를 선택하세요. 미리보기는 현재 폴더에 포함된 파일의 다운로드만
보여줍니다. 압축을 푼 사본에서는 ZIP 버튼이, 웹용 묶음에서는 편집용 MOV 링크가
숨겨집니다. 개별 영상은 `clips` 폴더에서도 바로 가져올 수 있습니다.

## 어떤 파일을 쓰면 되나요?

- **웹페이지·앱:** `이름.webm`. 배경이 투명합니다. 사용 환경에서 투명 재생이
  되는지 확인하세요.
- **HEVC 투명을 지원하는 환경:** `이름-hevc.mov`. 웹용 투명 영상의 대체 형식입니다.
- **영상 편집:** `이름.mov`. 배경이 투명한 ProRes 4444 파일입니다. 편집 타임라인에서
  원하는 화면 위에 올리세요. 용량이 크므로 편집용으로 사용하세요.
- **발표 자료·간단한 공유:** `이름.mp4`. 밝은 배경이 포함된 영상입니다.
- **정지 이미지:** `posters/이름.png`. 움직임이 필요 없는 곳에 쓰세요.

미리보기 화면은 HEVC와 WebM의 재생 가능 여부와 실제 투명도를 확인하고,
투명 재생이 어려운 브라우저에서는 MP4로 보여줍니다. 이때는 카드 아래에 안내가
나오며, 배경을 바꿔도 MP4 자체의 밝은 배경은 유지됩니다. 파일을 직접 여는 환경의
보안 제한으로 MP4가 선택될 수도 있습니다.

모든 영상은 무음입니다. 해상도·초당 프레임 수 등 정확한 파일 정보는
`manifest.json`에 있습니다.

## 캐릭터 기준과 수정 내용

**미코에는 손과 팔이 없습니다.** 오른쪽의 원래 둥근 포자는 손이 아닌 동반자입니다.
소품은 몸통 앞 가까이에 따로 떠 있습니다. 노트 연결과 포자 심기는 메모 읽기의
캐릭터 크기·위치·움직임에 맞췄습니다. 이전 메모 읽기·노트 연결·포자 심기에 추가됐던
손과 팔은 잘못된 결과였으며, 이번 파일에서는 원본 몸체로 교체했습니다.

**원본 활용 6종**은 원본 영상에 이동·회전·등장 효과를 더한 편집본입니다.
**원본 합성 7종**은 손 없는 원본 영상에 따로 떠 있는 소품과 작은 움직임을 더했습니다.
돋보기·전구·메모 정리는 메모 읽기와 같은 캐릭터 크기·위치·원본 타이밍을 사용합니다.
고개 인사는 원본 전체를 조금 내려 움직이고 기울여 표현하며, 눈과 동반자를 새로 그리지 않습니다.
캐릭터의 새 연기를 생성한 영상은 아닙니다.
**표정 동작 2종**은 발견·졸릴 때이며 참고 자료로 생성한 영상입니다.
반복 표시가 없는 영상은 한 번 재생하는 용도입니다.

반복 여부는 영상을 넣는 앱이나 편집 프로그램에서 설정합니다. 영상 파일 자체가
자동으로 반복되는 것은 아닙니다.

## 화면에서 사용할 때

- 기다림·완료 같은 상태는 모션 옆에 글로도 알려주세요.
- 완료 모션은 실제 작업이 성공한 뒤에 보여주세요.
- 반복 모션은 한 화면에 하나 정도가 적당합니다. 일시 정지 방법도 제공하세요.
- 기기의 ‘동작 줄이기’ 설정을 존중하세요. 이 미리보기는 자동 재생하지 않으며,
  해당 설정을 켜면 재생 중인 영상을 멈춥니다. 직접 재생하는 것은 가능합니다.

웹페이지에 넣는 코드 예시는 [영문 사용법](README.md)에 있습니다.

## 추가 동작과 제작 방식

제안했던 노트 연결·포자 심기·돋보기로 살펴보기·아이디어·고개 인사·메모 정리
6종을 모두 영상으로 담았습니다. 메모 읽기를 포함한 7종은 `myco-action-pack`
폴더에서도 사용할 수 있습니다. 기존 11종의 영상은 바꾸지 않았습니다.

9월 17일 Higgsfield 생성 요청은 크레딧 부족으로 거절됐습니다. 새 4종은
원래 미코 영상에 소품과 움직임을 합성해 완성했으며, 추가 결제는 하지 않았습니다.

[동작 제작 지시문](motion-prompts.md)은 향후 참고 자료로 생성할 때 쓰는 문서입니다.
완성본의 실제 동작과 제작 방식은 `manifest.json`에 기록했습니다.
편집용 전체 묶음에는 `production/additional-actions.mjs`에 재현 가능한 움직임 코드도 담았습니다.
가벼운 웹용 묶음에서는 제작용 파일을 제외했습니다.
